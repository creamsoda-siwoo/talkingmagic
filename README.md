# 말로 하는 마법 대결

주문을 버튼이 아니라 **문장으로 직접 적는** 마법 결투 게임입니다.
"얼음 벽을 세우고 그 뒤로 숨는다"처럼 쓰면 AI 심판(Claude)이 읽고 결과를 만들어 냅니다. 창의적일수록 강해집니다.

- **실시간 전투.** 캔버스에 그려진 마법사들이 실제로 싸웁니다. 내가 주문을 쓰는 동안에도 상대는 몇 초마다 기본 공격을 쏘고, 화면의 "다음 공격" 게이지와 지팡이 끝 고리로 미리 보입니다.
- 주문마다 창의력·개연성 점수를 매기고, 점수에 따라 피해가 정해집니다. 심판이 읽는 시간이 곧 시전 시간입니다.
- 세워 둔 방벽은 내 앞에 서서 기본 공격을 실제로 막아 주고(막을 때마다 지속 시간이 깎임), 내게 유리한 날씨는 공격을 빗나가게 합니다.
- **상대는 나를 배웁니다.** 같은 속성을 쓸 때마다 내성이 쌓여 피해가 20%씩 줄고(최대 60%), 내 습관을 "간파 노트"에 적어 다음 턴에 받아칩니다. 노트는 다음 상대와 다음 도전으로 이어집니다(브라우저에 저장, 시작 화면에서 지울 수 있음).
- **나도 상대를 배웁니다.** 상대마다 숨은 약점 속성이 있고, 맞히면 피해가 1.3배가 되며 화면에 드러납니다.
- 세 명을 차례로 쓰러뜨리면 승리.

## 실행

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # https://platform.claude.com 에서 발급
npm start                             # http://localhost:3000
```

API 키가 없으면 **연습 모드**로 켜집니다. 화면과 흐름은 같지만, 글을 이해하지 못하고 낱말 수와 속성 낱말만 보는 단순 규칙으로 판정합니다.

## 배포 (Vercel)

저장소를 그대로 Vercel에 올리면 됩니다. `public/`은 정적 파일로, `api/judge.js`는 서버리스 함수로 배포됩니다.
프로젝트 환경 변수에 `ANTHROPIC_API_KEY`를 넣어 주세요. 키는 서버에서만 쓰이고 브라우저로 나가지 않습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `public/index.html`, `style.css` | 화면 틀과 스타일 |
| `public/game.js` | 게임 진행 (실시간 타이머, 기본 공격, 판정 결과 적용) |
| `public/scene.js` | 캔버스 전투 장면 (마법사, 주문, 방벽, 입자) |
| `public/rivals.js` | 상대 목록과 수치 (서버·화면 공용) |
| `lib/judge.js` | 심판 프롬프트, Claude 호출, 판정 값 범위 고정 |
| `lib/mock.js` | 연습 모드 판정 |
| `api/judge.js` | Vercel용 `POST /api/judge` |
| `server.js` | 로컬 서버 (정적 파일 + `/api/judge`, IP당 분당 20회 제한) |

난이도(체력·최대 피해·기본 공격 간격과 피해·약점·내성 비율)는 `public/rivals.js`에서 바꿉니다.

심판 AI는 따로 학습시킨 모델이 아니라, `lib/judge.js`의 `SYSTEM` 프롬프트에 적은 규칙과 채점 예시를 따릅니다. 판정이 너무 후하거나 짜면 "채점 예시" 부분에 원하는 주문과 점수를 한 줄 더 적어 넣는 것이 가장 쉬운 조정 방법입니다.
